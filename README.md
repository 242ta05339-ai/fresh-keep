# FreshKeep

A Smart Food Management Application designed to reduce food wastage through inventory tracking, expiry monitoring, recipe recommendations, family sharing and notifications.

## Key Features
- User Authentication
- Inventory Management
- Expiry Tracking
- Notifications
- Recipe Suggestions
- Family Sharing
- Sustainability Tracking

## Technologies
- React
- TypeScript
- Tailwind CSS
- Vite
- Supabase

## Future Enhancements
- AI Food Recognition
- Enhanced Chat Assistant
- Advanced Analytics
- Voice-Based Food Entry
